# Security Policy

This project follows the [Eclipse Foundation Vulnerability Reporting Policy](https://www.eclipse.org/security/policy/).

Please follow the standard process for reporting a security problem:

- https://www.eclipse.org/security/baseline/

# Supported Versions

Support is provided for the most recent release:

- https://download.eclipse.org/eclipse/downloads/

All changes target the next scheduled quarterly release:

- [Release Schedule](https://eclipse.dev/simrel/?file=wiki/Simultaneous_Release.md)
